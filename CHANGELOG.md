# Changelog

## 0.1.0 — unreleased

First public version.

- Capture: area, window (shadow, optional background), fullscreen, previous area, self-timer, All-In-One, multi-display, freeze screen with crosshair and magnifier.
- Quick Access Overlay with copy / save / annotate / pin / OCR, drag & drop, swipe to dismiss, auto-close, restore.
- Annotate editor: 14 tools, undo/redo, rotate/flip, combine images, color palette, share, `.shot` project files.
- Background tool with 20 backdrops, custom images, presets and Auto Balance.
- On-device OCR and QR reading, floating pins, capture history, settings with recordable shortcuts.
- Command line: `Shot <action>`, `Shot open <file>`, `Shot capture-to <file.png>`.
